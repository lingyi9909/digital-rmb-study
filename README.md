# 数字人民币从零学习

这是一个持续维护的数字人民币（e-CNY）学习仓库。目标不是只会使用数字人民币钱包，而是从货币、银行与央行体系出发，逐步理解数字人民币的政策逻辑、金融架构、支付清算、技术实现、可编程能力、产业应用与跨境方向。

> 学习方法：先建立金融直觉，再进入数字人民币；每一课使用资产负债表、案例推演、Mermaid图和思考题。

> ⚠️ **制度提醒（2026-10-26核对）**：数字人民币已经于**2026-01-01升级为2.0存款货币型框架**。商业银行钱包中的余额是商业银行存款负债，实名钱包可计息并享有存款保险；不宜沿用2021年“全部直接央行负债、不计息、纯M0”的旧教材结论。阅读：[《2026数字人民币2.0政策更新与旧版勘误》](policy/2026-digital-rmb-2-0-update.md)。

## 必须区分的关键概念

~~~mermaid
flowchart TD
    CB["中国人民银行"] --> CC["现金 / 商业银行准备金：央行货币"]
    CB --> NET["数字人民币发行管理规则、数字币串与央行端平台"]
    NET --> BANK["2026年商业银行数币钱包：银行存款负债"]
    NET --> OTH["非银行机构钱包：独立负债和保证金安排"]
    BANK --> U["居民及企业数字支付"]
    OTH --> U
~~~

1. **财富不等于货币**：股票和房产不是直接按市值计入M2的存款货币。
2. **央行货币不等于商业银行货币**：现金与准备金、银行存款是不同层级负债。
3. **数字人民币有制度版本**：2021年现金型1.0与2026年存款型2.0负债属性不同。
4. **支付工具不等于资金性质**：微信支付、支付宝解决支付服务；数字人民币兼具国家级制度与基础设施能力。
5. **数字人民币不是单一公链币**：现行采用账户为基础、兼容价值、区块链和离线场景的混合设计。
