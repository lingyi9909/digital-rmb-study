# 第二周 Day 1｜数字人民币到底是什么？从1.0到2.0
> 制度核对日期：2026-10-26。注意区分**历史设计**与**当前制度**。

## 课程目标
解释e-CNY是什么；区分“法定数字货币系统”“数字币串”“钱包余额的负债主体”；掌握2026年1月制度转折。

## 一、为什么“数字”不是新鲜事？
今天工资到账、扫码买菜、手机转账早就主要靠电子账簿。要研究数字人民币，不能仅靠“钱被数字化”来解释创新：核心在于国家级数字货币制度、可互通的基础设施、支付结算与可扩展技术能力。

~~~mermaid
flowchart TD
 A["传统数字支付"] --> B["商业银行账户 / 支付机构支付网络"]
 C["数字人民币体系"] --> D["统一规则和标准"]
 C --> E["运营机构钱包"]
 C --> F["跨机构互通、数字币串与智能合约能力"]
~~~

## 二、先看历史：2021年和2026年不是同一套口径
|维度|数字人民币1.0（2021白皮书）|数字人民币2.0（2026-01-01起）|
|---|---|---|
|定位|现金型数字货币，主要定位M0|存款货币型2.0，钱包余额按流动性计入相应货币层次|
|个人持有的性质|现金型央行直接负债|在商业银行钱包中是商业银行存款负债|
|利息|现金型余额不计息|商业银行实名钱包余额按存款利率规则计息|
|银行经营|侧重数字现金流通运营|可纳入银行资产负债经营和存款准备金管理|
|存款保险|不能简单视同银行存款|银行类运营机构钱包余额纳入存款保险|
|运营方式|双层运营|进一步强化双层架构、央行侧统一基础设施|
|技术原则|不预设单一技术路线|账户为主、兼容价值模式、区块链及离线能力|

**需要精确：**不能据此推断所有数字人民币钱包都一模一样。非银行支付机构钱包受独立负债和100%保证金规则约束。

## 三、谁提供信用？谁负责基础设施？
以2026年商业银行钱包为例，央行负责发行管理规则、基础设施、统一标准和批发结算；运营商业银行为客户开立钱包，承担客户存款负债、利息与风控义务。
~~~mermaid
flowchart TD
 P["中国人民银行"] --> SYS["数字人民币央行端系统 DCEPS"]
 SYS --> B["银行运营机构"]
 SYS --> N["其他合规参与机构"]
 B --> U["个人、企业数字人民币钱包"]
 U --> M["线上线下商户、公共服务"]
~~~

2026年10月官方公开说明：央行端DCEPS与跨境结算平台CBETS协同，新的系统支持零售、批发、区块链、智能合约、跨境等场景。数字人民币业务运营机构拓展至30家。**这是制度与基础设施的演进，不是简单“换一个App”。**

## 四、举一个1000元的例子
你有一笔在银行A的普通活期存款1000元；希望使用银行A的数字人民币2.0钱包付款。

**同一家银行、相同客户的简化概念图：**
~~~mermaid
flowchart LR
 A["A银行普通存款 1000元"] --> B["A银行数字人民币钱包余额 1000元"]
 B --> C["银行仍需对客户承担存款负债"]
~~~
这一步可能是两种存款负债产品/账务之间的转换，不能按旧口径机械断言“银行负债消失、央行负债增加”。具体会计与资金流由产品与支付结算机制决定。

## 五、最容易混淆的三句话
- “数字人民币由央行主导”——正确，指规则和基础设施安排等；**不代表每个银行钱包余额均是央行对个人的直接负债**。
- “数字人民币不是支付宝”——正确，前者是法定数字货币和支付结算体系，后者主要是支付平台与服务。
- “数字人民币全靠区块链运行”——不正确。2026架构兼容账户、区块链和离线等多种形态，不能等同为某条公链上的Token。

## 六、检验你的理解
1. 为什么不能只用“纸币电子化”解释e-CNY？
2. 一位用户2026年在商业银行实名钱包有1万元，银行出现经营问题，这笔资金的法律负债主体是什么？保障机制是什么？
3. 为什么批发层仍保留央行结算货币？

答案要点：不同于支付界面，还涉及统一制度设施和数字支付能力；负债主体为商业银行，依法纳入存款保险；跨机构最终结算仍需高信用的央行层货币。
